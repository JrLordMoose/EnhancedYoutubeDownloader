## 🔍 Key Decisions
### cookies.txt over `--cookies-from-browser`
- **Why**: reproduced DPAPI failures with Edge and Chrome, and a lock error with Brave. Firefox isn't installed.
- **Alternatives rejected**: closing the browser first (doesn't fix the encryption); bundling a decryption tool (fragile and security-sensitive).

### Overwrite instead of "resume"
- **Why**: `NoPart=true` meant a re-run saw the truncated file as already downloaded. Overwriting is correct and safe, because paths are unique when a download is created.
- **Follow-up**: real `.part` resume is in the todo list.

### Subagents
4 read-only QC agents (design, settings, downloads, bug hunt), then 1 UI-fix agent restricted to the view files, to avoid edit conflicts.

  - **Solution**: load first, then a one-time migration flag.

  - **Solution**: `ThemeIndex`, primary #343838.
